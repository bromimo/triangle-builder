<h1 align="center">Triangle Builder</h1>

# Техническое задание

>Напишите CLI функцию, которая на вход принимает одно целое число N, представляющее количество элементов, и проверяет, можно ли из этого числа построить равнобедренный треугольник. 
>
>Если это возможно, функция должна вывести этот треугольник в виде чисел, если нет — вывести сообщение об ошибке.

## Требования к системе

- PHP 8.0+

### Использование в CLI

```bash
  php triangle.php 100
```
